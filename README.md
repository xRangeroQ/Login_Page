# 🌿 Basic Login Page
This project is a simple test case for user login and registration.

## ℹ️ Features
- Register and Login Page
- Show/Hide Password and Email

## 🔬 Technical Features
- **SQLite3** Database
- Hashed Passwords

## 🎯 Usage
PHP must be installed on your device!
```bash
php -S 127.0.0.1:80
```
